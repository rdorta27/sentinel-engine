Orquestador + router

Real El modelo etiqueta

Un LLM con instrucciones etiqueta la intención. No decide nada más. Una línea base de palabras clave responde el turno cuando el modelo falla.

En la demo
GLM 5.3 Flash en Fireworks AI con llamadas reales. La línea base de palabras clave es el respaldo de cada turno.
En producción
Los mismos pesos en Azure AI Foundry o Databricks.
