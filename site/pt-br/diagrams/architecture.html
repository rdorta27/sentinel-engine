Orquestrador + router

Real O modelo rotula

Um LLM com instruções rotula a intenção. Não decide mais nada. Uma linha de base de palavras-chave responde o turno quando o modelo falha.

Na demo
GLM 5.3 Flash no Fireworks AI com chamadas reais. A linha de base de palavras-chave é o reserva de cada turno.
Em produção
Os mesmos pesos no Azure AI Foundry ou no Databricks.
